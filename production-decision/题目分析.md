# 赛题建模思路分析

## 一、题目类型

**类型**：统计推断 + 随机过程优化（综合）

**判断依据**：问题一出现“信度、抽样检测、接收/拒收”；问题二至四出现“决策、检测、拆解、成本、次品率”。

## 二、子问题拆解

1. 以最小样本量判断供应商批次是否可接收；
2. 单工序下选择零配件/成品检测与不合格品拆解策略；
3. 树状多工序（8 零件、3 半成品、1 成品）重复问题二；
4. 把抽样误差带回问题二、三，重新决策并考察稳健性。

## 三、关键难点

1. 问题一缺少第二风险点，方案不唯一，需显式定义并做敏感性；
2. 售后调换、拆解重装会造成无限循环，需用再生过程或动态规划收敛；
3. 问题三策略空间大且装配图需准确还原，必须按半成品分组联合搜索。

## 四、推荐方案

问题一采用精确二项双风险最小样本量搜索；问题二、三采用认证件状态下的几何再生闭式模型并完全枚举；问题四采用 Wilson 单侧上界重估参数。备选方案为 SPRT 截尾序贯抽样与 Monte Carlo 模拟校验。

## 五、技术路线

```text
题目读取 -> 参数表 -> Q1精确抽样 -> Q2再生期望利润枚举
        -> Q3半成品组+成品联合搜索 -> Q4抽样上界重估 -> 检验与论文
```
